# Ejercicios de Lógica Proposicional

### Instrucciones
Para cada enunciado:

1. Identifique las proposiciones simples.
2. Asigne una variable lógica a cada proposición.
3. Exprese el enunciado usando exclusivamente los conectores:
   - Negación (¬)
   - Conjunción (∧)
   - Disyunción (∨)
   - Condicional (→)

No simplifique la expresión ni construya tablas de verdad.

---

### Ejercicio 1
"Si el sistema es seguro y no presenta fallos, entonces los usuarios acceden a la plataforma y no se pierde información."

---

### Ejercicio 2
"No es cierto que el experimento sea válido si los datos no son confiables o el método es incorrecto."

### Ejercicio 3
"Si el estudiante no aprueba el examen final y no entrega el proyecto, entonces no obtiene el grado."

### Ejercicio 4
"Si el modelo no converge, entonces el algoritmo falla o los parámetros no están bien definidos."

### Ejercicio 5
"No es cierto que, si el servidor está caído, entonces no hay conexión o el servicio funciona correctamente."

### Nota
Use paréntesis para evitar ambigüedades y respete la jerarquía lógica de los conectores.
